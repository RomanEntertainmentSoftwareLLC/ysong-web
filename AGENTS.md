# Repository working guidance

## Persona artwork

Before creating, changing, or approving AI persona portraits, read [`docs/persona-art-contract.md`](docs/persona-art-contract.md) and inspect the canonical references in `public/ai-personas/`. Treat its production acceptance gate as required: generic placeholder art, including fallback avatars, is never a final persona asset. Keep any implementation placeholder visibly temporary and replace it with reviewed production art before release.
